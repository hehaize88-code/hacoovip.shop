Hacoo Missing Items: How to Document an Incomplete Order

An incomplete parcel needs an item-by-item record. First establish what was supposed to be in that shipment, then document what actually arrived.

In this guide

  • Distinguish a missing accessory from an excluded accessory
  • Submit a focused missing-item report
  • Use weight information as supporting context

Start here: keep the packaging, check whether another parcel is listed, and compare the paid order with the contents received. Report the exact missing item or quantity through the order’s support route. A missing product and an entirely missing parcel need different evidence.

“My Hacoo order is incomplete” can describe several problems. One product may be absent, a set may contain fewer pieces than expected, or an accessory shown in a photograph may not actually be included in the purchased variant. A second shipment may also have its own tracking record. Sorting those possibilities first helps you describe the problem accurately without guessing where it happened.

Check the order and every shipment record

Open the paid order and record each item, selected variant and quantity. Then inspect the shipment entries associated with it. If the app shows separate parcels, note which items are assigned to each one and whether every parcel has arrived. Do not assume that one delivery status represents every item in a multi-item order.

Check for an item-level cancellation or refund message as well. A product that was removed before dispatch needs a payment check, while a product listed in a delivered shipment but absent from the parcel needs a contents investigation. If the assignment is unclear, ask support which shipment was supposed to contain the missing line.

For an order still moving through preparation or dispatch, use Hacoo order status explained. If no parcel arrived at all despite a delivery scan, the delivered but not received guide is the better starting point. This article concerns a package you have actually opened and inspected.

Make an item reconciliation table

RecordWhat to enterWhy it helps
Ordered lineProduct name, variant and quantity paid forDefines what you expected
ShipmentTracking reference or parcel assignmentConnects the line to a delivery
ReceivedCount and identifying labelShows the actual contents
DifferenceOne missing unit, missing component or uncertain assignmentStates the issue without exaggeration

For an illustrative example, an order for two identical shirts with one received has a quantity difference of one. An order for a shirt and trousers with only the shirt received has a different missing line. Keep that distinction in the report. This is a recordkeeping example, not a claim about a particular customer or fulfilment rate.

Use the order’s own item names where possible, but add a short identifying description if those names are unclear. Keep the purchase price separate from the full order total. Asking for the amount linked to the missing item is easier to assess than attaching a total that includes products already received.

Photograph the parcel before discarding anything

Hacoo’s public help center asks for the outer-package picture and payment invoice for a missing-item report. For missing accessories, it also asks for the received product and an explanation or picture identifying the absent part. Preserve that material while checking the active case for any additional requirements.

Take one clear photograph of the outside of the package and its label, then a wider photograph of everything received. Add closer photographs of individual labels, bags or components where they help identify the contents. Keep the original files. If you annotate a copy with arrows or item numbers, retain an unedited version alongside it.

A photograph of an empty space does not prove which item should have occupied it. Its value comes from the surrounding record: the paid order, parcel reference, packaging and received contents. Describe what each image shows rather than presenting a large, unexplained collection. If the packaging appears damaged, record its actual condition without stating who caused it.

Distinguish a missing accessory from an excluded accessory

For a set, bag, garment or electronic accessory, compare the purchased variant with the contents description saved at checkout. A styling photograph may show several objects even when the selected product includes only one. Check the item description, option name and any included-parts list together.

If the listing has changed, use the order snapshot or a screenshot you saved when buying. State which description you relied on. Do not use a different seller’s listing to prove what your order included. If there is no clear inclusion statement, ask support to confirm the contents of that exact variant before labeling the item incomplete.

Where a component is required for the received product to function, explain its role in plain language. Identify the corresponding attachment point or packaging compartment if visible. Avoid assembling, repairing or modifying the product merely to create a demonstration; show its received condition and ask what additional evidence is needed.

Submit a focused missing-item report

  1. Select the relevant order. Check the order reference against the invoice and parcel.
  2. Name the missing line. Include the variant and the number of units absent.
  3. Explain the shipment check. State whether another parcel is listed, still moving or already delivered.
  4. Attach labeled evidence. Include the order record, packaging and received contents.
  5. Request a specific review. Ask support to confirm the item allocation and the available resolution.

Keep a copy of the submitted text and attachments. If an upload fails or compresses a label beyond readability, correct that problem promptly. A short, readable report with a clear quantity difference is more useful than a long message that alternates between delivery, product quality and payment complaints.

Adaptable message: “Order [reference] lists [item/variant], quantity [number]. Parcel [tracking reference] arrived on [date], but contained [received quantity]. I checked [other shipment records]. Attached are the order invoice, outer packaging and received contents. Please confirm the shipment allocation and review the missing [item/quantity].”

Use weight information as supporting context

If the carrier receipt or label includes a weight, preserve it with its source. A printed weight, a carrier measurement and a home measurement are not necessarily the same type of record. Do not present a rounded billing weight as a precise inventory count. Packaging and service rules can also affect the number shown.

If you weigh the received contents, label the result as your own measurement and state whether packaging was included. Treat it as context for the investigation, not conclusive proof that a particular item was removed at a particular location. Avoid assigning responsibility without evidence from the shipment record.

Track the resolution at item level

Ask whether support is investigating the packing record, waiting for another shipment, offering a replacement or reviewing a refund. Record the answer and the next date or event it asks you to wait for. A replacement needs its own dispatch confirmation; an approved refund needs an amount, currency and destination.

If only part of the missing quantity is resolved, update the table rather than starting an unrelated complaint for the entire order. This keeps the remaining issue visible. Check any proposed remedy against the original item line, especially where several similar variants were purchased together.

Do not return the products you received unless the case gives you explicit instructions to do so. If a return is requested, confirm which items belong in it and how postage is handled. The return shipping cost guide explains the records needed before creating a shipping expense.

Follow up on the unresolved fact

When a reply does not answer the missing-item question, narrow the follow-up. Ask which parcel was assigned the item, which quantity was reviewed, or which attachment is unreadable. Attach the relevant record again with a one-sentence explanation. Avoid changing the account of what arrived between messages.

If a request is rejected, preserve the reason and use the rejected request checklist to address the specific evidence gap. If a refund is approved but has not appeared, move to refund tracking. Keep the order table and packaging until the resolution is complete so that the next reviewer can understand exactly what remains outstanding.
