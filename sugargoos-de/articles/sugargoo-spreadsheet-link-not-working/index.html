Sugargoo Spreadsheet Link Not Working? Check Stock and Variants

Diagnose a broken Taobao or Weidian link, a removed listing or a sold-out option. Use the original item ID to check a replacement before ordering.

When a Sugargoo spreadsheet link stops working, open the seller’s original product page first. Can you see the same item? Can you select the colour and size you want? If both answers are yes, try importing that product link again. If the seller has removed the listing or your particular size has sold out, copying the same address again will get you no closer to an order.

An old title can still say “in stock”

Take Weidian item 7698544537. The archived product record on FindQC retains the original “In Stock” wording in the title and shows the bag, yet its availability notice says the seller removed the product. Someone copying just the title and cover picture into a spreadsheet could easily miss the change. Save the item ID as a reference for the design. Check any replacement as a new offer, with its own seller, options and price.

Find the first place the link fails

A spreadsheet entry, a seller’s offer and the item displayed by Sugargoo are three separate records. Start at the spreadsheet, follow its link and note the first place where what you see differs from what you expected. If the link opens a buying-agent page, look for its original marketplace link. If all you have is a screenshot and no source address, ask whoever shared the find for the original listing. An image alone cannot identify which seller offered that particular version.

  • A shop, search page or promotion opens. Find the product inside the shop, then copy the link from the product itself.
  • The seller’s item opens and your option is selectable, but Sugargoo loads nothing. Check the copied address. A manual enquiry may help if a fresh link still fails.
  • The item opens but one option is greyed out. Check the complete size and colour combination before deciding whether to wait or choose another seller.
  • The marketplace explicitly says the item was removed. Look for a current listing and check the replacement as a new offer.
  • You see a login prompt, blank screen or timeout. Availability is still unknown. Check through the marketplace’s own app or ask the seller or Sugargoo to confirm the item ID.

Recover the original Taobao or Weidian product link

On the seller’s page, look for a product name, shop name and variant selector. Use the page’s share control to copy the product URL. On Weidian the controls may read 分享 (share) and 复制链接 (copy link). A shop homepage can open perfectly in your browser and still give the importer no particular product to load. If a shared message contains an invitation, a product title and a URL, paste just the URL into Sugargoo’s product search.

Check which item the copied address identifies. For example, a Weidian product link can contain itemID= followed by digits. Deleting everything after the question mark can remove the very number that distinguishes one item from the next. Copy a fresh address from the marketplace instead of rebuilding it from memory. For illustrated instructions, see the official Weidian link guide and Taobao product link guide.

Test the exact variant before you call an item sold out

Suppose a spreadsheet row describes a black jacket in size M. The seller’s page opens with a photo of the black jacket, but the default choice is blue in size S. Select black first and then M. Watch both selectors after the second click. If M disappears, a different size becomes active or the displayed price changes, make a note of the final selection. That is a more useful description for support than “the black jacket link is broken.”

Carry that comparison over to Sugargoo. Check the selected option’s wording and thumbnail, size, quantity and displayed price. A replacement strap can appear as a cheaper option beside a complete bag; a single unit can sit beside a pack. Look at the contents of the selected option before assuming that the lower price is a discount. If the seller page and the imported page disagree, save a screenshot of each with the relevant options visible and ask about the discrepancy before ordering.

When the source opens but Sugargoo cannot import it

Try the fresh product URL once and record what Sugargoo actually shows. A missing product title, an empty list of sizes and a message about a purchase restriction describe three different problems. “Could you check whether navy, medium, can be ordered from this seller?” gives the buyer something to verify. Include the original item URL and the option label, particularly if the translation uses the same English name for two different colours.

For a product that is identifiable but does not import, Sugargoo describes a manual route called DIY Order. Prepare the shop and product names, the variant, quantity, the seller’s current unit price and any separately listed domestic shipping charge. If the domestic fee is unclear, flag it in the notes. Keep the quoted item price separate from shipping to the warehouse and from later international postage. If Sugargoo displays a purchasing restriction, ask about that notice before taking any further step. The official DIY Order instructions show the fields.

Check a replacement listing before changing the spreadsheet

Start with the old record and the replacement side by side. Compare the marketplace, shop, item ID and option descriptions. Matching photographs tell you what the listings look like. To find out whether the offers match, check the seller’s own specifications and compare what arrives in the box. A new ID is worth recording even if the same shop published both listings.

For clothing, compare the seller’s stated garment measurements in the size you intend to buy. For a bag, look at external dimensions, strap type and the accessories included with the selected option. For shoes, ask which sizing convention the seller uses if the chart is ambiguous. A replacement whose photos match but whose measurements differ may still be a perfectly usable find; it belongs in the spreadsheet under its own description.

If you maintain the sheet, keep the original row while you check the substitute. Record when you last checked it, what failed and the new seller and item ID. A short note such as “old listing removed; replacement has a shorter strap” tells the next reader exactly what changed. If the only evidence was a login screen, label the link “could not verify” and leave a date. That distinction saves someone else from discarding a working find.

If you have already paid, check the existing order first

A link that expires after checkout raises a different question: what happened to the order already placed? Open that order in your Sugargoo account. Check the chosen option, purchase status and any messages about the seller. An unavailable public listing by itself tells you little about whether an earlier order was accepted, whether the seller dispatched it, or whether an agent is waiting for your reply.

Keep the discussion attached to the existing order where possible. Give the order reference and the exact option you agreed to, and ask whether the seller can supply it. If offered a substitute, compare its details before approving a change. Placing a second order while the first is unresolved leaves two purchases to reconcile. If the original item has already reached the warehouse, review the photos attached to your order and ask for the particular detail you need to identify it.

A support message you can use

“The seller page opens and I can select the dark-green bag with the long strap. After importing the same link, Sugargoo shows only the short-strap version. Here is the original item URL and a screenshot of each selection. Can you check which version the seller can supply and confirm the item price and domestic postage before purchase? Please ask me before choosing a substitute.” Change the details to match what you actually observed. Remove unrelated items, addresses and payment details from screenshots.

Once the issue is resolved, save the working product link alongside the shop name, item ID, option label and check date. The next time a saved link opens to a different photo or price, those four details give you a much better starting point than the spreadsheet title alone.
