Ordini, pagamenti e spedizione

Contatta la piattaforma di destinazione attraverso il canale di supporto mostrato nel tuo account o sul suo sito ufficiale. AllChinaBuy Pro non ha accesso ai record di account, pagamenti, immagini di magazzino, pacchi, ritorni o rimborsi.

Link e correzioni editoriali

Utilizzare il modulo di relazione editoriale pubblico per un percorso rotto, errore di fatto o destinazione obsoleta. Il modulo è ospitato nel repository pubblico di GitHub di questo sito web, quindi può essere richiesto un accesso GitHub e tutto ciò che viene inviato può essere letto pubblicamente.

Modulo di relazione editoriale aperto ↗

Includi l'indirizzo della pagina AllChinaBuy Pro, la destinazione inaspettata e la data che hai osservato il problema. Non inviare password, dettagli di pagamento, documenti di identità o altri dati privati.

Questioni di marchi o diritti

Un avviso di diritto dovrebbe identificare la pagina pertinente, il lavoro o il marchio protetto, la base della preoccupazione e un metodo di verifica. Utilizzare lo stesso modulo di relazione editoriale, ma mantenere la relazione pubblica iniziale limitata alle informazioni non riservate.
