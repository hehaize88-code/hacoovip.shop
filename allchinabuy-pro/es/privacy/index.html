Aviso de privacidad

Un directorio con necesidades mínimas de datos.

A partir del 18 de julio de 2026. Este aviso describe el sitio web público actual.

No cuenta de directorio

AllChinaBuy Pro no proporciona actualmente cuentas de usuario, procesamiento de pedidos, pagos, comentarios o un boletín informativo. No pide a los visitantes que presenten documentos de identidad o información de pago.

Transicións de búsqueda

Al enviar una búsqueda de catálogo, sus palabras clave se envían directamente al sitio web de destino en la URL. Desde ese punto, se aplican los términos de privacidad del sitio web de destino. No coloque contraseñas, datos de pago u otra información confidencial en un campo de búsqueda.

Información sobre la solicitud técnica

La infraestructura de hospedaje y seguridad puede procesar información estándar de solicitud, como dirección IP, datos de dispositivos o navegadores, horarios y páginas solicitadas para entregar y proteger el sitio web. El sitio web utiliza Google Analytics para medir las visitas y el rendimiento de la página; no procesa pedidos ni datos de pago.

Sitios web externos

AllChinaBuy Pro no controla cómo otro sitio web recopila o utiliza información. Revise la dirección de destino y su actual aviso de privacidad antes de crear una cuenta o enviar datos.

Cambios y contacto

Si se agregan análisis, formularios de correo electrónico u otras características de datos, este aviso se actualizará antes de que se activen esas características. Las preguntas de privacidad y las correcciones fácticas pueden presentarse a través del formulario de informe editorial público sobre el página de contacto. No incluya información confidencial o confidencial en esa forma pública.
