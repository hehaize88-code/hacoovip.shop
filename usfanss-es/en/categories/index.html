Before choosing a category

  • Shoes: compare the seller’s size chart and request measurements if sizing is unclear; decide whether you need the box.
  • Hoodies and T-shirts: measure a garment you own and compare chest, length and sleeves with the exact variant.
  • Jackets: check filling, fastenings, measurements and volume; a light item can still occupy a large parcel.
  • Sports jerseys and bags: confirm the version, customisation, included accessories and return conditions.
