Kakobuy Product Link Not Working? Recover the Listing and Size

Trace a broken spreadsheet or agent link to the seller's item, check what happened to your selected size or colour, and decide whether the order can go ahead.

By Kakobuys.shop Research Desk3 November 2026

Find where the link stopped working

Start with two tabs. Open the seller’s product page in one and the Kakobuy page reached from your spreadsheet in the other. The first question is whether you can identify the item on either side. A blank agent preview with a working seller page gives you something to recover. Two pages showing different items give you a reason to stop, even if both load quickly. A shop homepage gives you the seller’s name but leaves the product unidentified.

Save the original spreadsheet row before trying another link. Keep the seller URL if the row has one, the marketplace item number, the option you wanted, and the date. A screenshot that includes the selected option and the product title is more useful than a cropped picture of the garment. It lets you see whether the fault lies in opening the page, selecting an option or retrieving a price. Each calls for a different fix.

Work out which number identifies the product

Open the shoe record at /products/6045/ in this directory. The short number 6045 belongs to the directory address. The marketplace item number printed on the page is 7721490300. Someone copying the last number from the address bar would give a seller the wrong identifier. The name “shoes-60” offers little help on its own. For this record, use the source link on the page and compare its marketplace item number with the ten digits shown beside the product.

A spreadsheet row number, marketplace item number and purchase-order number serve different jobs. The row points to a line in someone’s list. The marketplace number identifies a listing on that marketplace. A purchase-order number identifies a transaction after an order has been created. Include the marketplace name beside its number when you ask for help. If there is already an order, also include its order number in your private message to support. Keep account details out of public spreadsheets.

Recover the original seller link from a shared page

Open the shared link as the person sent it. If it lands on a catalogue, look for the product-specific link on the relevant card. If it lands on an agent page, look for its link to the original seller. Copy the product page itself after it opens. A shop, a search result or a screenshot is useful for discovery, but none of them identifies which option you chose. If the share text contains several URLs, open them separately and label what each one shows.

For a worked example, the 18-style shoe record in our ASICS guide points to a product entry numbered 5932 in the source directory. Its Weidian link contains itemID=7730289026. Keep the full product link and that marketplace number together. A link from a messaging app may include tracking information or encode another URL inside it. You do not need to take it apart by hand when you can open the seller page directly. Removing every character after a question mark can remove the item number as well.

Check that the recovered page opens the same listing

The ASICS guide also links to a nine-style record with marketplace number 7706333190. Both titles describe a GEL-KAYANO 14. Both pages can open normally while pointing to different products in a spreadsheet comparison. A search for the model name could easily return the other one. Compare the marketplace, seller if visible, item number and selected option. The 18 and nine options are descriptions from the reviewed records. Check what each listing actually offers today before making a choice.

A different listing may still be worth considering. Give it a separate row and start the checks again. Do the same if the item number matches but the seller now describes a different product or shows different option pictures. Keeping the old and new rows apart prevents an old price, a size note or another buyer’s warehouse photo from silently becoming evidence for an item it never described.

When the colour or size disappears

Reopen the exact seller listing and choose the colour first, then the size if that is how its controls work. Write down the visible option wording, units and selected price. A shared link can open the right product without restoring your selection. If the size disappears only after you choose a colour, record that exact combination. Seeing “M” somewhere else on the page tells you little about availability in the colour you want.

On the Kakobuy side, repeat the selection and compare the two option summaries. Suppose the seller page offers a black top and black trousers on one card. A single black thumbnail on the imported page cannot tell you whether you are buying the top, the trousers or a set. Ask for the exact option wording and quantity before paying. If a size is missing on the seller page too, save that result and choose whether to wait or evaluate another listing. A repaired link cannot restore stock.

If the seller page works and the Kakobuy preview is empty

Use the original marketplace product URL in Kakobuy’s product search and open the returned item. Recheck the item number and selection after it loads. If the new preview opens on a different item, record that mismatch. Repeatedly submitting the same ambiguous link creates little new information. Kakobuy also lists a Fill & Buy option. If the service offers that route for your item, identify the seller link and describe the exact option and quantity for review.

A manual form is useful when you know precisely what the buyer is being asked to purchase. If the seller page is gone and you have only a picture, there is no reliable selection to pass on. When you see a purchasing restriction instead of a missing preview, ask the platform whether that item is eligible. When an order or payment already exists, return to its record. Start with the original transaction before making a second request for the same item.

Send one message that someone can act on

A helpful message gives the two links, the marketplace item number and the exact difference you saw. For example, write that the original listing opens, the seller shows the selected colour and size, and the imported page shows a different option. Ask whether that exact option can be selected, then say whether substitutions are acceptable. Attach a screenshot of the option on each page if it helps distinguish neighbouring choices. Crop out addresses or payment details.

Keep the reply with the listing it refers to. A seller’s confirmation of one colour and size does not settle the rest of the range. If support sends a replacement link, compare the item number, shop, quantity, selected price and option text again. A useful stopping point is a record you could hand to another person and have them select the same product unaided. If you cannot do that yet, mark the row “awaiting confirmation” and leave it out of the order.

Keep the two prices on separate lines if your recovery started with a price discrepancy. Record the amount on the seller page after choosing the variant, then the amount beside that same selection on the agent page, including the currency in each case. That gives support a reproducible comparison even if a search card still displays an older starting price.

Save the result for the next time the sheet changes

Update the row you actually used with the date, working seller URL, marketplace ID and complete selection. Add one short outcome such as “agent preview recovered”, “seller removed this size” or “different listing offered”. For an unresolved link, keep the old identifier visible. That gives the next reader a way to tell a repaired route from a replacement product and lets you resume without searching through every message again.
