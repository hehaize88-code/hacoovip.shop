Wrong Size or Wrong Item in Kakobuy QC Photos? Check Before Shipping

Compare your Kakobuy order with warehouse photos, document a size or item mismatch and send a clear replacement or return request before shipping.

A size tag showing M when you ordered L is a specific discrepancy you can report. A hoodie that looks small in a wide-angle photo needs a different check. Before asking for a return, open the exact order, identify the option you selected and compare it with evidence from your own warehouse item. Keep it out of the international parcel while the discrepancy is being checked. If packing is already underway, ask whether the warehouse can still pause it and wait for an answer.

01

Compare the option you paid for with the item in the photo

Start with the order detail as it stood when the purchase was made. Copy the item and warehouse references, selected size, colour or model, and the quantity. Save any seller note explaining how the option names correspond to a label or size chart. A listing can change after purchase. If opening it today selects the first available size automatically, that choice says little about your original order.

Now check the warehouse gallery against that record. On a multi-item shipment, look for differences in colour code, tag design or packaging that help identify the correct item. If two rows look alike and their photos may be reversed, flag both references and explain why. Asking the team to verify which pictures belong to which item can be quicker than arranging an exchange for stock that was correct all along.

02

A different label and a poor fit need different evidence

If the size printed on the physical garment differs from the size recorded on the order, save a readable close-up and a wider view of the same garment. A clear label comparison is often enough to request an identity check. If the label matches and the garment looks unexpectedly narrow, compare a measurement with the seller's chart for that selected variant. A label can be correctly printed on a garment whose cut does not suit you.

Use the seller's own measurement points. Some charts describe a flat width and others give the distance around the garment or suggest the buyer's body measurements. For example, a 52 cm underarm width and a 104 cm circumference need not disagree. They describe different ways to measure. Ask what the chart means if it is ambiguous. Do not double a figure without first checking the chart's units and method.

A useful photo shows the garment flat, the tape starting at the specified seam and its end visible on the other side. A tape pulled diagonally across folds can give a misleading result. If the original photo hides the starting mark, ask for one replacement photograph using the same method rather than presenting a guessed dimension as proof.

03

For a wrong colour or model, choose an identifying detail

A graphic in the wrong position might reflect a different version, a different size or simply a folded garment. Look for one feature the ordered variant is supposed to have, such as a specified pocket arrangement or a model code on the label. Capture the seller's option description alongside the warehouse detail. Explain the single difference a colleague can check without having to interpret the whole listing.

Colours need extra care. Deep green can look almost black under a warehouse light. A clear option code that contradicts the order is stronger evidence than the brightness of the photograph on your phone. If the code matches and the colour remains doubtful, request a wider photograph in more even lighting, ideally with the tag visible in the same set. Describe the colour as uncertain until you have a better comparison.

04

Check the contents before reporting a missing part

For a bag that seems to lack its shoulder strap, read the seller's description for the option you actually selected. A photograph of a styled bag may include accessories that a basic variant does not include. If the description explicitly lists the strap, save that line. Then check the interior photos for a pouch, a folded strap or a compartment the overview did not show.

Ask for a single layout photo of the bag, the packaging and the included parts if the service permits it. The fact that an accessory is out of frame does not establish that it was absent from the delivery. Likewise, a sealed carton may limit what can be verified without opening it. Ask how opening the package would affect return eligibility before you authorise the warehouse to disturb a seal.

05

Build a short evidence record the seller can follow

Choose the smallest set that proves the point. Usually you need the original option, one full view that identifies the item, and a close-up or measurement that demonstrates the difference. Name each piece clearly when you refer to it. Leave the original files intact and make a separate annotated copy if an arrow helps show a tiny printed code or an obscure seam.

An example might read, “Order shows navy size L. Photo A shows the whole hoodie associated with warehouse item [reference]. In Photo B, the sewn label reads M. Please verify the label against the order before shipping.” That tells the reader what was ordered, what the evidence shows and what action you want. You do not need to speculate about who selected the wrong piece to make the request actionable.

06

Choose a request that matches the problem

When identity is uncertain, ask for verification first. When the mismatch is clearly documented and you still want the item, ask whether the correct option is available for an exchange. If it is unavailable or the order is time-sensitive, ask which return or refund options the seller will accept. Check the displayed terms, domestic shipping costs and any handling requirements before choosing.

Here is a message you can adapt. “For warehouse item [reference] from order [reference], I selected [exact option]. The attached [photo or measurement] shows [observable difference]. Please confirm whether this is the correct item. If a mismatch is confirmed, I would prefer [exchange for the specified option / return if eligible]. Please tell me the applicable deadline, any costs and the next action I need to take.”

A changing stock level may affect the answer. If an agent offers a different size or another model, ask for the exact alternative and its price before agreeing. If you have a deadline for receiving the parcel, check whether the alternative will require another domestic delivery and inspection. A quick agreement to a substitute can leave you with a second item that still does not fit your original requirements.

07

Keep the after-sales clock separate from warehouse storage

A long warehouse allowance gives you time to plan an international parcel. It does not establish how long a seller will accept a return or whether a particular option can be exchanged. Read the terms attached to the live order and retain any dated instruction you receive. Ask what needs to be submitted before the displayed deadline. If time is short, report the observed mismatch promptly and state which extra view is still pending.

Before moving other items into a parcel, check that this item has been left out. A message asking customer service to investigate is different from a confirmed warehouse hold. If a parcel already exists, include its reference and ask whether the item can still be removed at its current stage. Wait for a clear response before planning around that possibility.

08

Verify the outcome on the correct order line

If the warehouse confirms a gallery mix-up, reopen the photographs and check that they now match the correct item. If the seller sends a replacement, inspect the replacement's own label and option before closing your notes. An acknowledgement that a return was requested is only the first step. Check the recorded outcome and any amount or credit actually issued against the terms you accepted.

Finally, save the original discrepancy and the resolution together. If the replacement looks right, that record can be as short as the original order line, the new label photo and the confirmation. If the case remains open, reply with the one detail still unresolved. A precise record lets you explain the next step without repeating the whole story each time the person handling the order changes.
