Kakobuy-QC-Farbe prüfen – Lichtstich oder falsche Variante?

Prüfe Farbcode, Lichtquelle, Schatten und Materialreflexe, bevor du eine vermeintlich falsche Farbe im Lager meldest.

Das Produktfoto zeigt Olivgrün, das Lagerbild wirkt braun. Bevor du daraus auf die falsche Lieferung schließt, trenne drei Dinge: die bestellte Variante, die Oberfläche vor der Kamera und die Wiedergabe auf deinem Bildschirm. Schon eine Aufnahme unter gemischtem Licht kann dieselbe Jacke an zwei Stellen unterschiedlich erscheinen lassen.

In diesem Ratgeber
  1. Vom Variantenmerkmal ausgehen
  2. Das gesamte Bild als Hinweis lesen
  3. Je nach Oberfläche den Winkel wechseln
  4. Einen brauchbaren Vergleich anfragen
  5. Ein zweiteiliges Set als Vergleich
  6. Den Verdacht präzise formulieren
01

Vom Variantenmerkmal ausgehen

Sichere Farbname und gegebenenfalls Code aus der Bestellposition. Suche nach einer entsprechenden Angabe am Artikel oder auf einer klar zugeordneten Kennzeichnung. Marketingnamen wie „Stone“ oder „Graphite“ sind keine normierten Farbmuster. Vergleiche nur Bilder der tatsächlich bestellten Ausführung. Ist der sichtbare Code ein anderer, ist das ein konkreterer Prüfgrund als eine leichte Änderung des Farbeindrucks.

02

Das gesamte Bild als Hinweis lesen

Sieh auf weißen Etiketten, neutralen Flächen und Hauttönen nach einem gemeinsamen Farbstich, ohne sie als kalibrierten Farbreferenzwert zu behandeln. Gelbliche Beleuchtung kann mehrere helle Gegenstände gleichzeitig warm erscheinen lassen. Ein bläulicher Schatten kann einen schwarzen Ärmel fast marineblau wirken lassen. Liegt das verdächtige Detail gerade dort, prüfe einen zweiten Bildausschnitt unter gleichmäßigerem Licht.

03

Je nach Oberfläche den Winkel wechseln

Satin, glänzende Beschläge und Flor verändern ihre Helligkeit stark mit der Richtung. Bei Wildlederoptik können zwei benachbarte Partien durch verschiedene Strichrichtung unterschiedlich dunkel aussehen. Beobachte, ob sich der helle Bereich zwischen zwei Aufnahmen mit Kamera oder Licht bewegt. Ein Unterschied an genau derselben Naht kann eher auf verschiedene Materialien oder Zuschnitte hinweisen und verdient eine gezielte Nachfrage.

04

Einen brauchbaren Vergleich anfragen

„Bitte die ganze Vorderseite und das Farbkennzeichen der Position [Referenz] bei möglichst gleichmäßigem Licht ohne direkten Blitz aufnehmen. Im bisherigen Bild ist der linke Ärmel stark verschattet.“ Fordere keine beliebige Reihe stärker bearbeiteter Bilder an. Ein Ausschnitt kann gut für die Kennzeichnung sein, doch die Übersicht zeigt, ob beide Stoffpartien überhaupt denselben Lichtbedingungen ausgesetzt sind.

05

Ein zweiteiliges Set als Vergleich

Bei einem Set wirken Jacke und Hose auf zwei Einzelfotos verschieden grün. Die Jacke wurde nahe einer hellen Wand fotografiert, die Hose auf einer dunklen Unterlage. Bitte um eine gemeinsame Aufnahme beider Teile auf demselben Hintergrund, sofern sie derselben Bestellung zugeordnet und zusammen zugänglich sind. Damit vergleichst du die Stoffe unter ähnlicherem Licht. Wenn nur die Bündchen abweichen, prüfe, ob sie laut Modell ohnehin aus einem anderen Material bestehen. Bleibt auf derselben gemeinsamen Aufnahme ein deutlicher Unterschied zwischen gleichartigen Stoffpartien, kannst du diesen Befund präziser an den Verkäufer weitergeben.

06

Den Verdacht präzise formulieren

Unterscheide einen falschen Farbcode, einen Unterschied zwischen zwei Teilen desselben Sets und eine unerwartete Gesamthelligkeit. Frage bei einem klar abweichenden Code nach Prüfung der gelieferten Variante. Beurteile bei einem subtilen Tonunterschied, ob die verbleibende Unsicherheit für deinen Kauf entscheidend ist. Ein Screenshot auf einem unkalibrierten Bildschirm liefert keinen exakten Farbwert und keine Garantie für das Aussehen im Tageslicht.
