Couleur sur une photo QC Kakobuy – éclairage ou mauvaise variante ?

Vérifiez code couleur, ombres et reflets avant de signaler un écart entre le visuel vendeur et la photo de l’entrepôt.

L’annonce montre une veste olive et la photo d’entrepôt paraît brune. Pour chercher l’origine de la différence, distinguez la variante choisie, la surface réellement photographiée et le rendu sur votre écran. Un éclairage mixte peut déjà produire plusieurs teintes sur une seule pièce.

Dans ce guide
  1. Partir de l’option achetée
  2. Examiner la photo entière
  3. Tenir compte de la surface et de l’angle
  4. Demander une comparaison suffisamment contrôlée
  5. Comparer deux pièces d’un ensemble
  6. Qualifier le résultat
01

Partir de l’option achetée

Conservez le nom et, lorsqu’il existe, le code couleur figurant dans votre sélection. Comparez-les à l’indication lisible sur la pièce ou sur une étiquette clairement associée. Les noms commerciaux tels que « pierre » ou « graphite » ne constituent pas des références colorimétriques normalisées. Si un code lisible diffère, vous avez un élément plus précis à faire vérifier qu’une impression générale de couleur trop chaude.

02

Examiner la photo entière

Observez les zones claires et les éléments supposés neutres sans les traiter comme une charte calibrée. Si toutes les surfaces blanches tirent vers le jaune, l’éclairage ou la balance des blancs peut affecter l’ensemble. Une ombre froide peut faire paraître une manche noire presque marine. Cherchez le même détail dans une autre zone de l’image ou sur une seconde vue avant de conclure.

03

Tenir compte de la surface et de l’angle

Le satin, le métal poli et les matières à poil peuvent changer fortement de luminosité quand l’angle varie. Un tissu brossé peut même présenter deux bandes de clarté différente selon le sens du poil. Voyez si la zone claire suit la lumière entre deux photos. Un contraste qui reste le long d’une même couture mérite une vérification ciblée, surtout si les deux panneaux devraient être dans la même matière.

04

Demander une comparaison suffisamment contrôlée

« Pour [référence], pourriez-vous montrer toute la face avant et le code couleur sous une lumière régulière, sans reflet direct ? Sur la vue actuelle, la manche gauche se trouve entièrement dans l’ombre. » Évitez les demandes vagues de photos plus jolies ou plus saturées. Une vue large permet de voir si les deux parties sont exposées de la même manière, tandis que le gros plan sert à lire le code.

05

Comparer deux pièces d’un ensemble

Le haut et le bas d’un ensemble paraissent de deux verts différents sur des photos séparées. Si les deux pièces sont accessibles ensemble, demandez une photo sur le même fond dans la même lumière. Comparez d’abord deux panneaux de matière similaire. Un bord-côte peut naturellement renvoyer la lumière différemment du tissu principal. Un contraste persistant entre deux panneaux comparables est plus exploitable.

06

Qualifier le résultat

Écrivez séparément un code incorrect, un désaccord entre deux éléments d’un ensemble et une simple différence de luminosité par rapport à l’annonce. En présence d’un code clairement différent, demandez de vérifier la variante livrée. Pour une nuance subtile, décidez si l’incertitude reste importante pour votre usage. Une capture d’écran sur un écran non calibré ne fournit pas la couleur exacte que vous verrez dehors.
