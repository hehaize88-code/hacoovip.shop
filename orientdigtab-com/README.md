# orientdigtab.com
Independent Orientdig discovery site. Source data: cnfanshp.com; true seller variants from linked Weidian listings. No database/admin backend.

Build: `npm run build`. Deploy: `npx wrangler deploy` from this folder. Cloudflare Git root directory: `orientdigtab-com`. Both orientdigtab.com and www.orientdigtab.com bind to this Worker; www redirects to HTTPS apex.

Image-search snapshot includes 35,654 discovered images: all27,262 readable main-source images and8,392 linked seller images. 6,022 searchable products; three unavailable details excluded. Weidian metadata coverage is partial. Source merchandise remains live; image index is a dated derived snapshot, stored as gzip parts. Rebuild snapshot to incorporate future image additions.

24 locales; daily exchange-rate conversion; genuine SKU links. No credentials or third-party referral codes. Real XML sitemap index plus24 product-language sitemaps and a page sitemap. Original preview remains separate.
