Returns and warehouse decisions

Superbuy Returns & Refunds: What to Do After a QC Problem

A practical Superbuy return guide: identify a QC problem, document the order, confirm eligibility and costs, and distinguish a refund from a balance withdrawal.

Found a QC problem? Pause the parcel decision

If warehouse photos suggest that an item is wrong, damaged or incomplete, first keep it out of an international parcel while you investigate. Record the order number, selected option and exact concern. A photo can reveal a reason to ask questions without proving what caused the problem. Your immediate goal is a documented decision: accept the item, obtain better evidence, request an exchange or ask whether a return is possible.

Treat this guide as an evidence workflow, not a promise that every order can be refunded. Superbuy’s buying guide identifies order enquiry and warehouse photos as parts of its process. The seller, product, purchase stage and applicable terms still matter. Check the current order screen and ask for the relevant deadline promptly. Free warehouse storage does not mean that a seller’s return opportunity remains open for the same period.

Match the request to the current order stage

Before writing to support, establish where the item actually is. A request to cancel an unpurchased order is different from returning goods that have reached the warehouse. After international dispatch, a parcel issue also needs the shipment record. Use the status shown in your account and the most recent message, not the date you placed the order or an assumption based on another buyer’s experience.

The table is a triage checklist rather than an eligibility policy. Ask which action is still available and what approval is needed before any movement occurs. If a parcel has been submitted but has not visibly left the warehouse, ask immediately whether it can be held; do not assume that a message automatically stops packing. Keep the confirmation attached to the same order or parcel conversation.

Build evidence that identifies the actual mismatch

Start with identity. Save the original listing, seller, chosen colour, size, quantity and any agreed specification. Then match those details to the warehouse item number. A general product picture is less useful than the option actually ordered. If two similar items are in storage, label each image clearly so that a return request cannot accidentally refer to the correct item while describing the wrong one.

Next, distinguish a visible fact from an interpretation. “The order says blue, while the label in photo two says black” is stronger than “this looks bad.” For a size issue, state what was measured, the unit and both endpoints. A flat chest width is not a body circumference. When lighting, folding or camera angle makes the evidence uncertain, request the missing view before treating the difference as established.

Keep an unedited copy of each image and use a separate annotated copy to point out the concern. Include an overall view as well as a close-up, because a close-up alone may not identify the item. Avoid sending a large collection of unrelated pictures. A short numbered set, with one sentence explaining each image, makes it easier for another person to verify the same issue independently.

Confirm eligibility before approving return shipping

Do not apply one return rule to every marketplace or product. Superbuy’s storefront warns that certain secondhand or unverifiable-source purchases cannot be returned or exchanged. Other cases still require the specific seller and order terms to be checked. Ask whether the request is being assessed as a wrong item, a defect, a size concern or a change of mind; those descriptions are not interchangeable.

Ask for the deadline applicable to this order, the required item condition and the next approval step. Preserve tags, accessories and packaging while the request is unresolved unless the agent gives a clear alternative instruction. If the seller refuses, request the reason and the evidence used to reach that decision. An exchange, additional inspection or an agreed partial remedy may be discussed, but none should be presented as automatic.

Send one clear return or exchange request

A useful message contains the order number, the ordered option, the observed mismatch and the remedy you are requesting. Explain whether you want clarification first or are ready to request a return. Ask for eligibility, any deadline, the itemised cost and the expected next step. Keep the request in the relevant account conversation so the person handling it can connect the evidence with the purchase record.

For example: “Order [number], option [colour and size]. The attached order record shows [specification], while warehouse photo [number] shows [observation]. Please review whether this item can be returned or exchanged. Before proceeding, confirm the deadline, costs, packaging requirements and refund destination. Please keep this item out of my international parcel while the request is reviewed, and confirm whether that hold is possible.” Replace every bracket with accurate information.

  • State the requested remedy without exaggerating what the photos prove.
  • Attach the order evidence and a small, numbered image set.
  • Ask who must approve the request and whether a hold is confirmed.
  • Confirm the return address through the agent before authorising movement.
  • Save the decision and follow up in the same conversation.

Compare the complete cost of each available remedy

A product-price refund and a cost-free return are different outcomes. Before authorising anything, ask for a breakdown of return delivery, any applicable service charge, original domestic delivery and services already completed. Ask which amounts would be refunded and which would remain payable. Responsibility depends on the confirmed case and terms; a public guide cannot assign every shipping charge to the buyer or seller in advance.

Use a simple decision record. Write the amount expected back, every confirmed deduction and the cost of an alternative replacement. Leave unknown amounts marked as unknown. For a low-value item, paying for additional photos, return delivery and another purchase may change the decision. For a serious mismatch, better evidence may justify proceeding. Compare only remedies actually offered, and keep affordability separate from whether the item meets your needs.

Track the refund separately from any balance withdrawal

Record each stage: request submitted, seller decision, return dispatched if required, seller receipt, refund approved and money credited. A status such as “return accepted” does not by itself show that funds have arrived. If progress stops, ask which stage is pending and what evidence or action is needed. Include the relevant order or return tracking number instead of opening unrelated conversations that lose the chronology.

Then verify where the refund went. A credit visible in a platform balance is not the same thing as money received by your bank or card account. If you want to withdraw a balance, check the available withdrawal process, destination, amount, possible charges and displayed timing separately. Compare the actual credit with the written decision, and ask about any difference before assuming a payment-provider delay or a missing refund.

Reduce return problems on the next purchase

Save the selected option and seller terms before paying, especially when a listing has many colours or ambiguous size labels. Ask about a decisive specification before purchase rather than relying on a thumbnail. At warehouse arrival, review the item promptly and keep a short decision log. Mark it as ready to ship, awaiting evidence or under review; this prevents an unresolved item from being accidentally included in a larger parcel.

For a delivered parcel, preserve the outer packaging, labels, contents and photos that show the condition on receipt. Describe damage or missing contents factually and use the account’s appropriate after-sales channel. The Help Center provides after-sales and account-balance help categories, but an individual case still needs its own record. Keep that record until the issue and any subsequent payment movement have been reconciled, then use what you learned to improve the next order.
