QC の問題が見つかりましたか?小包の決定を一時停止する

倉庫の写真から、商品が間違っている、破損している、または不完全であることが示唆される場合は、調査する間、まずその商品を国際小包の外に保管してください。注文番号、選択したオプション、正確な懸念事項を記録します。写真は、問題の原因を証明しなくても、質問する理由を明らかにすることができます。当面の目標は、商品を受け入れるか、より良い証拠を入手するか、交換を要求するか、返品が可能かどうか尋ねるなど、決定を文書化することです。

このガイドは、すべての注文が返金されることを約束するものではなく、証拠となるワークフローとして扱ってください。 Superbuy の購入ガイドでは、注文の問い合わせと倉庫の写真がプロセスの一部であると明記されています。販売者、製品、購入段階、および適用される条件は依然として重要です。 Check the current order screen and ask for the relevant deadline promptly. Free warehouse storage does not mean that a seller’s return opportunity remains open for the same period.

リクエストを現在の注文ステージと照合します

サポートにメールを送信する前に、アイテムが実際にどこにあるかを確認してください。未購入の注文のキャンセルリクエストは、倉庫に到着した商品の返品とは異なります。国際発送後の荷物発行には発送記録も必要です。注文日や他の購入者の経験に基づいた推測ではなく、アカウントに表示されるステータスと最新のメッセージを使用してください。

この表は、適格性ポリシーではなく、トリアージ チェックリストです。どのアクションがまだ利用可能で、動作が発生する前にどのような承認が必要かを尋ねます。荷物が提出されたものの、倉庫から出ていないことが明らかな場合は、すぐに保管できるかどうか問い合わせてください。メッセージのパッキングが自動的に停止するとは考えないでください。同じ注文または荷物のやり取りに確認書を添付して保管してください。

注文段階役立つ最初のリクエスト保持する証拠
まだ購入していませんキャンセルがまだ可能かどうか尋ねます。注文状況と支払い記録。
購入または販売者の発送エージェントに売り手のオプションを確認するよう依頼してください。販売者の発送ステータスと要求された救済策。
倉庫に保管小包を提出する前にレビューをリクエストしてください。注文したオプション、QC 画像と測定値。
小包を送信しました取り置きが可能かどうか尋ねます。小包番号と書面による回答。
海外発送または配達適切な小包のアフター問い合わせを開きます。追跡、梱包証拠、配送写真。

実際の不一致を特定する証拠を構築する

アイデンティティから始めましょう。元のリスト、販売者、選択した色、サイズ、数量、および合意された仕様を保存します。次に、それらの詳細を倉庫の品目番号と照合します。一般的な製品の写真は、実際に注文したオプションよりも役に立ちません。類似した商品が 2 つ保管されている場合は、返品リクエストで誤って間違った商品を説明しているときに正しい商品を参照することがないように、それぞれの画像に明確にラベルを付けてください。

次に、目に見える事実と解釈を区別します。 「注文書には青と書かれているのに、写真 2 のラベルには黒と書かれている」という方が「見た目が悪い」よりも強いです。サイズの問題の場合は、測定した内容、単位、および両方のエンドポイントを記載します。平置き胸幅は胴囲ではありません。照明、折りたたみ、またはカメラの角度によって証拠が不確実になる場合は、違いが確立されたものとして扱う前に、欠けているビューをリクエストしてください。

Keep an unedited copy of each image and use a separate annotated copy to point out the concern.拡大図だけではアイテムを識別できない可能性があるため、拡大図だけでなく全体図も含めてください。無関係な写真を大量に集めて送信することは避けてください。各画像を 1 文で説明する短い番号付きセットを使用すると、別の人が同じ問題を独立して検証することが容易になります。

返品発送を承認する前に資格を確認してください

1 つの返品ルールをすべてのマーケットプレイスまたは製品に適用しないでください。 Superbuy の店頭では、特定の中古品や購入元が確認できないものについては返品や交換ができないと警告しています。その他の場合でも、特定の販売者と注文条件を確認する必要があります。リクエストが間違った商品、欠陥、サイズに関する懸念、または考えの変化として評価されるかどうかを尋ねます。これらの説明は互換性がありません。

この注文に適用される期限、必要な商品の状態、次の承認ステップを尋ねます。エージェントが明確な代替指示を与えない限り、リクエストが未解決である間はタグ、付属品、および梱包材を保管してください。売主が拒否した場合は、その理由とその決定に至った証拠を要求します。交換、追加検査、または合意された部分的救済策が議論される可能性がありますが、いずれも自動的なものとして提示されるべきではありません。

明確な返品または交換リクエストを 1 件送信してください

役立つメッセージには、注文番号、注文したオプション、観察された不一致、および要求している解決策が含まれています。最初に説明が必要か、それとも返品をリクエストする準備ができているかを説明してください。資格、期限、費用の内訳、予想される次のステップについて尋ねます。リクエストを処理する担当者が証拠を購入記録と関連付けることができるように、リクエストを関連するアカウントの会話に残しておきます。

例: 「注文 [番号]、オプション [色とサイズ]。添付の注文記録には [仕様] が示されていますが、倉庫の写真 [番号] には [観察] が示されています。この商品が返品または交換できるかどうかを確認してください。続行する前に、期限、費用、梱包要件、および返金先を確認してください。リクエストが検討されている間、この商品を国際小包の中に入れずに保管し、保留が可能かどうかを確認してください。」すべての括弧を正確な情報に置き換えてください。

  • 写真が証明していることを誇張せずに、要求された救済策を述べてください。
  • 注文の証拠と番号の付いた小さな画像セットを添付します。
  • 誰がリクエストを承認する必要があるか、保留が確認されるかどうかを尋ねます。
  • 移動を許可する前に、エージェントを通じて返送先住所を確認してください。
  • 決定を保存し、同じ会話でフォローアップします。

利用可能な各治療法の合計コストを比較します

商品価格の返金と無償返品は結果が異なります。何かを承認する前に、返品の配送、該当するサービス料金、元の国内配送、およびすでに完了したサービスの内訳を尋ねてください。どの金額が返金され、どの金額が未払いのままになるのかを尋ねます。責任は確認されたケースと条件によって異なります。公共ガイドは、すべての配送料金を事前に購入者または販売者に割り当てることはできません。

単純な意思決定記録を使用します。返される予定の金額、確認されたすべての控除、および代替交換の費用を記入します。不明な金額は不明としてマークしたままにしておきます。低価格商品の場合、追加の写真、返品配送、および別の購入に料金を支払うと、決定が変わる可能性があります。重大な不一致の場合、より良い証拠があれば手続きが正当化される可能性があります。実際に提供されている治療法のみを比較し、その商品がニーズを満たすかどうかとは別に、手頃な価格を考慮してください。

残高の引き出しとは別に返金を追跡します

各段階を記録します: リクエストの送信、販売者の決定、必要に応じて返品の発送、販売者の受領、返金の承認、入金。 「返品受領」などのステータスは、それだけでは資金が到着したことを示すものではありません。進行が止まった場合は、どの段階が保留中なのか、どのような証拠や行動が必要なのかを尋ねます。時系列を失う無関係な会話を開く代わりに、関連する注文または返品の追跡番号を含めてください。

次に、返金先を確認します。プラットフォームの残高に表示されるクレジットは、銀行口座やカード口座に受け取られるお金と同じではありません。残高を引き出したい場合は、利用可能な引き出しプロセス、宛先、金額、可能な手数料、表示されるタイミングを個別に確認してください。決済プロバイダーの遅延や返金の不足を想定する前に、実際の信用額と書面による決定を比較し、差異について尋ねてください。

次回購入時の返品問題を軽減

特に商品に多くの色や曖昧なサイズラベルがある場合は、支払う前に選択したオプションと販売条件を保存してください。サムネイルに頼るのではなく、購入前に決定的な仕様について質問してください。倉庫に到着したら、すぐに商品を確認し、短い意思決定記録を残してください。発送準備完了、証拠待ち、または審査中としてマークを付けます。これにより、未解決のアイテムが誤って大きなパーセルに含まれることが防止されます。

配達された荷物については、外箱、ラベル、内容物、受領時の状態を示す写真を保管してください。内容物の破損または欠落を事実に基づいて説明し、アカウントの適切なアフターセールス チャネルを使用してください。ヘルプ センターには、アフターセールスおよびアカウント残高に関するヘルプ カテゴリが用意されていますが、個々のケースには独自の記録が必要です。問題とその後の支払いの動きが調整されるまでその記録を保管し、その後、学んだことを使用して次の注文を改善します。
